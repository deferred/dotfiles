# Comments

- Explain why, not obvious actions.
- Keep comments short and precise.
- Update comments with the code.
- Keep temporary context out of source comments.
- Usually use imperative mood; sometimes use indicative mood.
- Use simple present tense.
- Use active voice.
- Use modal verbs.
- Write complete sentences, but start with lowercase and omit the final period.
