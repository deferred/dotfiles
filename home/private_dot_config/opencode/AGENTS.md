# Writing guidelines

## Meet user needs

- State the reader and the goal before you write.
- Write only what the reader needs.
- Make content specific.
- Make content clear and to the point.

## Create a clear structure

- Put the most important information first.
- Break up the text with headings.
- Use one H1 for the title. Start body headings at H2.
- Write descriptive headings.
- Do not write generic headings like 'Introduction'.
- Frontload your headings.
- Write active headings. Start a heading with a verb when possible.
- Write removable headings. The content must make sense without them.
- Use question headings only for FAQ content.
- Do not use technical terms in headings, unless you explained them before.
- Use bullet lists and numbered steps to reduce duplication.
- Do not use footnotes. Put the information in the body text.
- Write a summary at the top of the page.
- Do not repeat the summary in the first paragraph.

## Use clear language

- Use plain English.
- Use plain English even for specialist readers.
- Do not use a long word when a short word works.
- Avoid buzzwords and jargon.
- Break a vague term into what you actually do.
- Avoid words that end in '-ion' and '-ment'.
- Explain a specialist term in plain English the first time you use it.
- Use 'must' for a requirement.
- Use 'need' for a procedural step.
- Use 'can' for an optional action.
- Avoid vague terms like 'You may be able to'.
- Use the active voice.
- Use the passive voice only when the outcome is more important than the agent.
- Write paragraphs of 5 sentences or less.
- Split sentences longer than 25 words.

## Use the right tone

- Avoid subjective adjectives that make the text emotive or like spin.
- Address one reader directly.
- Address the reader as 'you'.
- Write instructions in the imperative.
- Do not write 'please' or 'please note'.
- Do not use block capitals for large amounts of text.
- Write gender-neutral text in the third person.
- Give a full name before you use a pronoun or an abbreviation.

## Write clear titles

- Make each title unique and informative.
- Keep the title to 65 characters or less.
- Make sure the title makes sense by itself.
- Write a user focused, clear and descriptive title. Do not use the official title.
- Frontload the title with the main subject.
- Use an abbreviation without explanation only if it is well known.
- Write an unknown abbreviation in full, then the abbreviation in brackets.
